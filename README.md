# cargo-size-of
`cargo-size-of` is a hastily coded tool meant to assist in finding the sizes/alignments of structs in a Rust project. The tool was mostly written with AI.
I will probably not be maintaining this tool that much, given that it doesn't do much. If it stops working, you can open an issue.
If you have any ideas for features that you want to add yourself, feel free to open a PR, but I won't be responding to any feature request issues.
